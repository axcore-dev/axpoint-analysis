## 11:02 — 사용 중인 프로그램 선택 동작 수정

`사용 중인 프로그램`(랜딩 3/3)의 태그 선택 두 건.

- **'없음'을 골라도 기타가 풀리지 않았다.** `toggleSystem`이 `systems`만 `["없음"]`으로 바꾸고
  `otherOpen`은 그대로 둬서, 입력창이 열린 채 기타 태그도 선택 상태로 남았다. '없음'을 고르면
  입력창을 닫고 입력값·직접 입력한 프로그램까지 함께 정리한다
- **기타를 다시 눌러도 해제되지 않았다.** `onClick`이 `setOtherOpen(true)`라 켜기만 했다.
  토글로 바꿨다. 기타 태그의 선택 상태는 `입력창 열림 || 직접 입력한 프로그램 있음`이므로,
  해제할 때는 입력창을 닫고 담긴 프로그램도 함께 뺀다 — 그래야 실제로 꺼진다

기타를 **켤 때** '없음'을 건드리지는 않는다. 이름을 실제로 담는 순간 `addOtherSystem`이
'없음'을 빼므로 모순이 남지 않고, 켜자마자 빼면 선택이 0개가 되어 진행 버튼이 잠긴다.

문구는 손대지 않았다.

### 검증

브라우저 실측 — 기타로 '더존' 담기 → '없음' 클릭 시 기타·입력창·'더존' 모두 해제되고 '없음'만
선택. 기타 두 번 클릭 시 열렸다가 정상 해제.

### 커밋 문구

- `fix: 사용 중인 프로그램 — '없음' 선택 시 기타 해제, 기타 재클릭 해제` (푸시 완료)
