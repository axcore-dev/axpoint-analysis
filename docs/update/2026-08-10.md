### 섹션 재배치 (핵심)

기존: 헤더·레벨 → 레이더+상세 → 8대 영역 서술 → 워크플로우 → 종합 분석 → CTA
개편: ① 진단 개요 → ② 카테고리 분석 → ③ 워크플로우 분석 → ④ 업무영역 분석 → ⑤ 종합분석 → CTA.
워크플로우(전체 흐름)가 영역별 서술(부분 평가)보다 먼저 오도록 순서를 뒤집었다.

### 이슈별 반영

- **① 진단 개요 거시 해설** — 기업 카드 하단에 서사 `detail.overview` + `strategy`를 서술
  블록으로 배치(새 AI 필드 없이 기존 데이터 재활용). 다음 섹션 안내 한 줄 추가.
- **② 문항 코드 숨김** — `renderRich`에 문항 코드 패턴(`[A-Z]{2}-\d{2}`) 치환 추가.
  판정 응답의 questionText로 바꾸고, 괄호 코드 나열은 삽입구로 보고 걷어낸다.
  원문 코드는 '근거' 팝업에만 남는다. "47개 문항 중 N개" 수치에는 뜻 설명 한 줄
  ("자료가 부족한 문항은 분석 보류로 두고 감점하지 않아요") 부착.
- **② 5축 카드** — 모두 보기/선택 토글 패널을 없애고 축 카드 5장을 병목 순으로 항상
  펼침(이름·점수·평균 바·한 줄 소견·상세 서술·업무영역 연계·분석 문항 수·근거 버튼).
  서버에 없는 서술은 그 줄만 생략. 레이더 클릭 시 해당 카드로 스크롤·강조.
- **③ 워크플로우 분석** — WorkflowStandard 래퍼 대신 다른 섹션과 같은
  Inner(1080px)+SectionHead+Card 컨테이너로 감쌈(v8 이슈⑥ UI 통일). 읽기 모드라
  비교하기 버튼 없음. `workflow_note`(업무 흐름 진단) 문단을 차트 바로 아래 고정.
- **④ 업무영역 카드 다음 행동** — 과제 화면과 같은 `GET /tasks` 카탈로그에서 추천
  과제를 functionArea로 매칭해 '개선 과제'(제목+기대효과, 최대 3건)·'활용 가능한
  AI'(services 집계)를 붙이고 '이 영역 과제 보러 가기' CTA로 /tasks 이동.
  추천이 없는 영역은 블록 자체를 생략.
- **⑤ 종합분석 여정 요약** — 제목 아래에 "자료 33건 → 8대 영역 분류 → 47문항 중
  N개 판정 → 기록 끊김 N곳" 한 문단(files API 건수 + WorkflowChart 병목 수 콜백
  `onBottlenecks`로 구성). §1로 옮긴 overview 폴백은 중복이라 제거.
- **⑥ 우측 TOC** — lg(1024px) 이상에서 그리드 우측 216px 레일에 sticky 목차.
  IntersectionObserver 스크롤 스파이 + 클릭 smooth scroll + 상단 읽기 진행률 바.
  lg 미만은 CSS로 숨김.

## 21:55 — 어드민 멀티 에이전트: 지시문 편집 UX 개선 (v9 B5·B6·B8)

수정 파일: `app/admin/agents/page.tsx`, 신규 `components/admin/PromptDiff.tsx`.
AgentCanvas.tsx·admin/layout.tsx는 병렬 작업 중이라 건드리지 않음.

### 수정됨 배지 + v0 대비 diff (B5)

- 저장 버전이 활성이고 내용이 코드 기본값과 다른 지시문을 '수정됨'으로 판별
  (버전만 활성이고 내용이 같으면 수정으로 안 침). 그래프 탭 캔버스 위에
  '수정됨 N' 배지 + 지시문 칩 스트립(클릭 시 편집 팝업), 팝업 헤더에도 배지.
- 편집 팝업 'v0과 비교' 토글: 편집 중 텍스트 vs 코드 기본값을 줄 단위 diff로
  표시(추가 초록·삭제 붉은 배경). 외부 라이브러리 없이 줄 단위 LCS 직접 구현
  (`PromptDiff.tsx` — 앞뒤 공통 줄 제거 후 DP, 백만 셀 초과 시 통삭제+통추가 폴백).
- v0 내용은 별도 조회 없이 `/api/admin/prompts` 목록 응답의 `defaultSystem`을
  그대로 사용(백엔드가 이미 실어 보냄).

### 모델 선택 강화 (B6)

- 모델 드롭다운 각 항목에 스펙(컨텍스트 K·입력 $x.xx/1M)과 '권장' 표시,
  선택된 모델 아래에 컨텍스트·입출력 단가·구조화 출력 지원 요약 + 권장 칩.
- 데이터는 `/api/admin/prompts` 응답의 `modelMeta`·`recommended`(백엔드 병렬
  추가 예정 계약). 필드가 없으면 아무것도 그리지 않아 기존과 동일하게 동작.

### 프롬프트 편집기 강화 (B8)

- 글자 수 + 근사 토큰 수(글자수÷2.5, 근사임은 툴팁) 표시.
- 자리표시자 안내의 {이름}을 버튼으로 — 클릭 시 커서 위치에 삽입.
- v0에 있는 자리표시자가 편집본에서 빠지면 경고 배너(저장은 막지 않음).
- 저장 2단계: '지시문 저장' → 변경 요약(추가 N줄·삭제 N줄, diff 재사용) 표시
  → '저장 확정'. 초안을 고치면 확인 단계가 풀린다.
